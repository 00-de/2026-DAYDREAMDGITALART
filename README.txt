============================================================
 DayDream Plus デジタルモザイク　開発版（0.7）
============================================================

■ いまできること
  ・日本語の画面（写真モザイク／文字モザイクの切り替え）
  ・文字モザイク：文章を入力すると、タイル化した完成イメージをその場でプレビュー
  ・写真モザイク：メイン写真の選択とプレビュー、タイル数・出力サイズ・必要メモリの表示
  ・タイル用の写真を最大2,000枚まで読み込み（フォルダー追加／複数ファイル選択／ドラッグ＆ドロップ）
    壊れた写真は飛ばし、中身が同じ写真は自動で除外。進み具合の表示と中止ができます
  ・サムネイル一覧と「詳細」画面（読み込めなかった理由も確認できます）
  ・2回目からは解析結果を再利用するので一瞬で読み込めます。前回の写真は起動時に自動で読み込みます
  ・モザイクの生成（写真モザイク・文字モザイク）。進み具合の表示と中止ができます
  ・「生成前」「生成後」の切り替え、拡大・縮小
  ・PNG／JPEG で保存（保存先・ファイル名・解像度・JPEG画質・設定情報の保存）
  ・写真をコレクションから外す（サムネイルを選んで「選んだ写真を外す」／右クリック／Deleteキー）
    元の写真ファイルは削除しません。外した写真はフォルダーを読み直しても戻りません
  ・写真が集まって文字になるアニメーション（200種類）
    プレビュー再生、MP4動画（縦1080×1920など）・GIFアニメ・PNG連番で書き出し
  ・自動更新（起動時に新しい版を確認 → 1クリックで更新 → 自動で再起動）

■ アプリの作られ方（自動ビルド）
  GitHub Desktop で「Push origin」すると、GitHub が自動で次を行います。
    テスト → 版番号を自動で上げる → EXE化 → セットアップEXE作成
    → インストール・起動・アンインストールの検証 → 合格したら公開
  公開された版は、インストール済みのアプリが自動で見つけて更新します。
  進み具合は GitHub のリポジトリの「Actions」タブで見られます。

■ セットアップEXEの入手
  GitHub のリポジトリ画面 → 右側の「Releases」→ 最新版の
  DayDreamPlusDigitalMosaic_Setup.exe をダウンロードしてダブルクリック。

  ※ 初回は「WindowsによってPCが保護されました」と表示されることがあります。
    これは発行元の電子署名（有料の証明書）が無いアプリに出る表示です。
    「詳細情報」→「実行」で進めてください。

■ プライバシー
  写真はすべてパソコンの中だけで処理し、外部に送信しません。
  インターネットに接続するのは「更新の確認」だけで、
  送るのはアプリ名とバージョン番号のみです。
  ヘルプ →「起動時に更新を確認する」のチェックを外すと、通信は一切しません。

■ フォルダーの説明
  app\                  アプリ本体のプログラム
  tests\                自動テスト
  assets\               アイコン
  installer\            インストーラーの設定（Inno Setup）
  tools\                自動ビルド用の補助プログラム
  .github\workflows\    自動ビルドの手順書（GitHub が読みます）
  DESIGN.md             設計書
  TEST_RESULTS.md       テスト結果の記録
