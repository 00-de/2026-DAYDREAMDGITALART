============================================================
 DayDream Plus デジタルモザイク　開発版 0.1.0（フェーズ1）
============================================================

■ このフォルダーについて
  まだ「完成アプリ」ではありません。
  フェーズ1では、アプリの土台となる次の部品を作り、自動テストで確認しました。

    ・画像の安全な読み込み（JPG / JPEG / JFIF / PNG）
    ・文章から白黒の文字マスク画像を作る仕組み（文字モザイクの土台）
    ・設計書（DESIGN.md）とテスト結果（TEST_RESULTS.md）

  画面（ウィンドウ）はフェーズ2で作ります。
  セットアップEXE（DayDreamPlusDigitalMosaic_Setup.exe）はフェーズ10で作ります。

■ ファイルの説明
  DESIGN.md         … 設計書（画面設計・仕組みの説明）
  TEST_RESULTS.md   … テスト結果の記録
  check_env.bat     … Windowsで環境チェックとテストを行う（ダブルクリック）
  check_env.py      … 上の .bat から使われるチェック用プログラム
  requirements.txt  … 必要な部品（ライブラリ）の一覧
  app\              … アプリ本体のプログラム
  tests\            … 自動テスト

  ※ .md ファイルはメモ帳でも開けます。

■ Windowsでの確認方法（フェーズ2の最初に一緒に行います）
  手順は次の回に1ステップずつご案内します。今は何もしなくて大丈夫です。
